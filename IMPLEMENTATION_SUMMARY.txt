=================================================================
              核心功能说明
=================================================================

### 登录流程
1. 用户在登录标签页输入：手机号/用户名/邮箱 + 密码
2. 点击"登录"按钮
3. 系统验证输入
4. 调用 loginWithPhone(phone, password)
5. 成功后关闭页面返回主页

### 注册流程
1. 用户切换到注册标签页
2. 输入：手机号/用户名/邮箱 + 密码 + 昵称(可选)
3. 点击"登录"按钮（按钮文本保持一致）
4. 系统验证输入
5. 调用 registerWithPhone(phone, password, nickname)
6. 成功后显示提示并自动切换回登录页
7. 可使用新账号登录

### 第三方登录
1. 点击微信/支付宝按钮
2. 系统触发第三方认证
3. 成功后登录并关闭页面

              后端集成建议

### 必需的API变更
1. 登录端点 (POST /auth/login-phone)
   - 请求：phone, password
   - 响应：accessToken, refreshToken, user

2. 注册端点 (POST /auth/register-phone)
   - 请求：phone, password, nickname
   - 响应：accessToken, refreshToken, user

3. 密码要求
   - 最小长度：8字符
   - 建议：包含字母和数字

### 安全建议
- 使用bcrypt加密密码
- 实现登录失败计数器
- 添加速率限制
- 支持密码重置流程
